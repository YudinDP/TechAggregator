![Status](https://img.shields.io/badge/status-stable-brightgreen)

> TechAggregator - проект нацеленный на создание сервиса, позволяющего людям изучать и сравнивать разных товары сферы цифровой техники.   
> Ключевыми аспектоми проекта является упор на сравнение цен из разных популярных магазинов, маркеплейсов и прочих площадок с целью помочь пользователю выбрать самую подходящую технику с наибольшей выгодой, а также обучающая составляющая
